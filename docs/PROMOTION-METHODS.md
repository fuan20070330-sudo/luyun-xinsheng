# 宣传方法参考

登录后的“创作要求”页面提供 8 种宣传方法，可多选。选中方法会写入四类成果的参考说明、生成提示词和 Markdown 导出文件。

## 方法清单

### 1. 品牌故事线

- 适用目标：建立品牌记忆，解释“为什么做这件事”。
- 执行方式：用时间、人物选择、具体工序和产品场景形成连续叙事。
- 推荐指标：完读率、停留时长、品牌搜索量。
- 生成影响：品牌故事采用“起点—手艺—今天—受访者责任”的结构。

### 2. 文化知识科普

- 适用目标：降低理解门槛，让消费者看懂老字号和非遗内容。
- 执行方式：把工序、器物、地域文化拆成可回答的问题和知识点。
- 推荐指标：收藏率、搜索量、评论中的问题数量。
- 生成影响：内容日历增加工艺知识和问答型选题。

### 3. 场景化种草

- 适用目标：把品牌信息转化为消费场景。
- 执行方式：围绕节令、家庭分享、伴手礼、下午茶等真实场景组织文案。
- 推荐指标：互动率、商品点击、转化率。
- 生成影响：多平台文案增加“何时、和谁、为什么需要”的场景表达。

### 4. 传承人 IP 化

- 适用目标：建立可识别的人物资产和持续内容来源。
- 执行方式：使用受访原话、工作过程和选择背后的原因，不让旁白替代本人表达。
- 推荐指标：关注增长、人物内容完播率、评论互动。
- 生成影响：品牌故事和年轻化方案增加受访者视角。

### 5. 节点内容日历

- 适用目标：形成稳定发布节奏，覆盖节令和品牌节点。
- 执行方式：按周规划主题、平台、事实依据和品牌确认点。
- 推荐指标：发布频次、复访率、节点转化。
- 生成影响：内容日历按四周输出，并标注品牌确认事项。

### 6. 用户共创与 UGC

- 适用目标：借助真实用户体验扩大社会证明。
- 执行方式：发起家乡记忆、食用场景、节令餐桌等征集活动。
- 推荐指标：UGC 数量、分享率、真实评论占比。
- 生成影响：可生成征集话题和用户参与型选题。

### 7. 搜索长尾内容

- 适用目标：承接用户已有的主动搜索需求。
- 执行方式：围绕“怎么做、为什么、有什么不同、适合什么场景”组织问答内容。
- 推荐指标：自然搜索流量、长尾词排名、页面停留。
- 生成影响：多平台文案增加问答标题和可检索知识点。

### 8. 线上线下联动

- 适用目标：把内容流量连接到门店、工坊和直播。
- 执行方式：将工坊参观、门店体验、直播问答与内容日历连接。
- 推荐指标：到店、扫码、留资、直播观看。
- 生成影响：内容日历加入体验型任务和后续转化提示。

## 组合建议

- 品牌新人认知：品牌故事线 + 文化知识科普 + 传承人 IP 化。
- 新品或节令推广：场景化种草 + 节点内容日历 + 线上线下联动。
- 长效内容资产：文化知识科普 + 搜索长尾内容 + 用户共创。
- 高风险文化主题：任何组合都必须通过事实和文化校验，并由品牌方确认。
