# 提示词版本记录

## v1.2.0｜当前版本

版本标识：`brand-safe-content-v1.2`

变更：

- 明确 AI 只能把 `facts` 数组中的文字当作确定事实。
- 要求每条确定事实后保留 `[Fxxx]` 引用编号。
- 禁止补写年份、荣誉称号、人物、工艺、销量和功效。
- 增加医疗功效、荣誉真实性、绝对化宣传、无依据年份、无法验证工艺和营养健康表述规则。
- 远程模型输出改为 `main`、`matrix`、`script` 三个 JSON 字段。
- 远程调用失败时要求网关回退到本地确定性引擎，并向前端发送明确进度说明。
- 三份成果统一附带模型、提示词版本、事实引用和生成时间。

适用模型：

- 本地确定性演示引擎。
- OpenAI 兼容 `/chat/completions` 接口。
- 用户可通过 `AI_MODEL` 环境变量替换模型名称。

## v1.1.0

变更：

- 增加小红书、抖音、微信公众号、多平台矩阵四种表达结构。
- 增加品牌语气的输入字段。
- 增加选题矩阵和 30 秒短视频脚本。
- 对没有来源的类别生成“待核实”记录。
- 增加人工审核留痕字段。

## v1.0.0

初始版本：

- 从品牌资料提取基础事实。
- 生成单平台内容。
- 保留 AI 原稿与人工修改稿。
- 导出 Markdown。

## 后续版本计划

- `v1.3`：事实来源页码、文件哈希和证据包导出。
- `v1.4`：地区老字号名录、非遗名录等权威来源核验适配器。
- `v1.5`：品牌审核人角色、权限和多人会签。
- `v1.6`：平台发布前合规规则包和可配置策略。
