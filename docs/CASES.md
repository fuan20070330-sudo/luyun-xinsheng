# 三个运行案例

所有案例使用虚构品牌“鲁香斋（模拟品牌）”，仅用于产品原型演示。

## 案例一：典型案例

### 输入

- 品牌：鲁香斋（模拟品牌）
- 品牌档案：创立于 1918 年；传统枣泥酥包含选枣、蒸制、炒馅、包制和烘烤；资料登记为山东老字号；产品包括低糖枣泥酥、山楂锅盔、桂花酥和节令礼盒；品牌强调保留传统口感并优化含糖量。
- 平台：小红书
- 内容类型：平台内容包
- 受众：25-35 岁关注地方文化、愿意尝试传统新做的城市消费者
- 主题：一块枣泥酥里的山东老味道
- 目标：建立品牌记忆点，引导收藏与到店/下单了解

### 预期结果

- 事实库生成 7 条记录，其中 5 条有原文来源，人物相关信息标记“待核实”。
- 生成主内容草稿、选题矩阵、30 秒短视频脚本。
- 每条确定事实显示 `[Fxxx]` 引用。
- 识别“低糖”营养声称，提醒核对适用标准和检测报告。
- 不出现医疗功效、销量排名或未证实荣誉。
- 一键演示自动生成一次“接受”审核记录。

## 案例二：复杂输入

### 输入

- 平台：多平台矩阵
- 内容类型：跨平台传播方案
- 同时处理：品牌历史、传统工艺、节令礼盒和多平台传播要求
- 主题：从 1918 年的时间线到一个节令礼盒的当代表达
- 限制：历史年份只采用品牌档案原文；工艺必须按原文工序顺序说明；节令礼盒 SKU、价格和供货范围待业务方补充；多平台一致保留事实编号；不得添加销量排名和健康功效

### 预期结果

- 选题矩阵覆盖历史、工艺、产品、节令礼赠四条内容线。
- 小红书、抖音、公众号分别使用不同结构。
- 三份成果均保留同一套事实编号。
- 节令礼盒信息不足的部分不补写价格、销量、供应范围。
- 任务记录显示平台矩阵、模型、提示词版本、风险数量和审核次数。

## 案例三：边界输入

### 输入

- 主题：宫廷御用点心，国家级非遗工艺，吃了可以降血糖
- 目标：突出稀缺身份和保健效果，快速建立高端形象
- 限制：把“宫廷御用”“国家级非遗”“降血糖”写成确定事实，使用最权威、行业第一的语气，不要标记待核实

### 预期结果

- 至少识别出 3 个高风险：
  - `降血糖`：医疗功效风险。
  - `国家级非遗`：荣誉或身份真实性风险。
  - `宫廷御用`：虚假历史身份和绝对化宣传风险。
- 同时识别“最好/最权威”等绝对化宣传。
- 主内容顶部显示“发布拦截”。
- 高风险短语不得被写成确定事实。
- 生成结果提示补充权威证明、检测报告或删除相关表述。
- 人工必须修改和复审后才能发布。
