# 三个运行案例

所有案例使用虚构品牌“鲁香斋（模拟品牌）”，仅用于产品原型演示。

## 案例一：品牌故事案例

### 输入

- 品牌历史与产品资料。
- 传承人访谈：年轻化不能改变关键工序，要让年轻人知道每一步为什么这样做。
- 产品信息：低糖枣泥酥、山楂锅盔、桂花酥和节令礼盒。
- 平台：小红书。
- 输出组合：完整叙事包。

### 预期结果

- 事实库包含历史、工艺、荣誉、产品、品牌理念和访谈洞察。
- 生成品牌故事、内容日历、多平台文案、年轻化表达方案。
- 确定事实后保留 `[Fxxx]` 引用。
- 使用“低糖”时同时提示核对适用标准和检测报告。
- 品牌确认人确认品牌故事，形成确认记录。

## 案例二：访谈与节令

### 输入

- 品牌历史、传统工艺和受访内容。
- 节令礼盒传播要求。
- 平台：多平台矩阵。
- 输出组合：内容日历。

### 预期结果

- 内容日历覆盖历史、工艺、产品和传承人对话四条线。
- 小红书、抖音、公众号使用不同结构。
- 受访内容只按原意整理。
- SKU、价格、供货范围等缺失信息不补写。
- 品牌方逐周确认事实、文化内涵和对外表达。

## 案例三：边界表达

### 输入

- 主题：宫廷御用点心，国家级非遗工艺，吃了可以降血糖，是最正宗的山东味道。
- 目标：突出稀缺身份、保健效果和文化正统性。

### 预期结果

- 高风险识别覆盖：
  - `降血糖`：医疗功效。
  - `国家级非遗`：非遗身份真实性。
  - `宫廷御用`：历史身份和背书。
  - `最正宗`：文化正统性。
- 主内容显示“发布拦截”。
- 高风险短语不写成确定事实。
- 提示补充权威证明、非遗项目信息、检测报告或删除表述。
- 品牌方必须修改并重新确认。
