# 创新点说明

## 一句话定位

老字号叙事工坊不是普通的 AI 文案工具，而是一套把老字号档案、口述、工艺和荣誉转化为可追溯品牌记忆与可信内容的系统。

## 1. 品牌记忆图谱

系统把事实转换为品牌关系图：

- 品牌
- 时间节点
- 工艺动作
- 产品
- 荣誉
- 人物
- 品牌理念
- 证据来源

每条关系都保留事实编号、来源权威度和原始文件指纹。用户可以看见品牌不是一段抽象故事，而是一组可以核验的关系。

## 2. 文化 DNA

系统从资料中提取：

- 必须保留的文化关键词
- 不可改写的年份、荣誉、人物和工艺事实
- 不得进入对外文案的文化禁忌
- 平台可以调整的语气、标题、场景和结构

生成结果会显示“文化保真度”。平台表达可以变化，但文化核心不能被模型改掉。

## 3. 证据缺口与追问闭环

系统不只标记“待核实”，还会主动生成补证问题，例如：

- 年份来自哪份档案？
- 荣誉由哪个机构授予，证书编号是什么？
- 哪些工序绝不能省略？
- 受访人的姓名、身份和师承关系是什么？
- 产品通常在什么场景下被使用？

这些问题可以复制成品牌方访谈提纲，形成“发现缺口 → 追问 → 补证 → 更新知识库 → 重新生成”的闭环。

## 4. 内容护照

每次生成都会生成一张内容护照，记录：

- 护照编号
- 品牌和平台
- 模型、提示词版本
- 事实引用编号
- 来源文件和 SHA-256 指纹
- 文化保护词和禁忌词
- 风险数量和高风险数量
- 人工审核次数
- 每个成果的内容哈希
- 最终状态

内容护照让一篇发布内容可以被追溯，而不是只剩下一段无法验证的 AI 文本。

## 5. 与普通 AI 文案工具的区别

普通工具关注“生成得快不快”。

本系统关注：

1. 这句话来自哪里？
2. 这个品牌文化不能让模型改掉什么？
3. 还缺什么证据，应该向谁追问？
4. 平台改写后事实是否仍然一致？
5. 谁确认了发布，修改了哪些内容？
6. 这篇内容的完整身份证明是什么？

## 6. 完整工作流

```text
品牌资料和口述
→ 品牌记忆图谱
→ 文化 DNA 提取
→ 证据缺口发现
→ 补证访谈提纲
→ 多平台内容生成
→ 事实与文化保真校验
→ 人工审核
→ 内容护照
→ 发布与效果回流
```
