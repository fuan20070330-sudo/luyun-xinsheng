# 使用说明

## 快速演示

1. 打开网页后确认顶部连接状态：
   - “已连接”：使用实时 WebSocket 网关。
   - “连接中”：正在探测网关。
   - “已断开”：自动使用浏览器本地确定性引擎。
2. 点击首页“一键评审演示”。
3. 系统自动完成：
   - 载入鲁香斋模拟品牌。
   - 提取品牌事实。
   - 生成主内容草稿、选题矩阵和 30 秒短视频脚本。
   - 扫描风险并关联事实编号。
   - 用“演示评审员”接受主内容，生成审核留痕。
4. 滚动到“生成结果”查看三份成果，也可导出 Markdown 审核包。

## 新建品牌

1. 在“品牌知识库”中选择“+ 新建品牌”。
2. 填写品牌名称、品牌类型和品牌语气。
3. 粘贴资料，或在“导入 TXT / MD / JSON / CSV”中选择文件。
4. 点击“提取品牌事实”。
5. 检查每条事实的分类、来源、置信度和状态。
6. 如果某条信息没有原文来源，应保持“待核实”，不要人工改写成确定事实。

## 内容生成

1. 选择发布平台：
   - 小红书：体验、种草、笔记语气。
   - 抖音：强钩子、短句、镜头节奏。
   - 微信公众号：完整叙事和品牌解释。
   - 多平台矩阵：同一事实资产拆成多平台表达。
2. 选择内容类型。
3. 填写目标受众、传播主题、内容目标和限制条件。
4. 点击“通过 WebSocket 生成内容”。
5. 观察实时进度和 `content.delta` 内容片段。
6. 等待三个成果生成。

## 风险处理

1. 查看每张风险卡片的等级、原文位置、判断依据和事实关联。
2. 高风险内容不得直接发布。
3. 优先采用卡片中的修改建议：
   - 医疗功效：删除功效承诺。
   - 虚假荣誉：补充权威来源，否则标记待核实。
   - 绝对化宣传：改为可量化、可证明的表达。
   - 无依据年份：补充档案或删除年份。
   - 工艺描述：补充生产记录和工艺流程依据。
4. 修改后由人工重新审核。

## 人工审核

- “接受”：确认事实引用、表达和风险边界。
- “编辑”：进入编辑态，保存后保留 AI 原稿并记录人工修改稿。
- “标记风险”：当前成果继续保持风险状态，等待修改。
- “复制”：复制当前成果文本。
- 每条审核动作会记录审核人、任务、成果、动作、前后内容和时间。

## 导出

点击“导出 Markdown”可生成包含以下内容的审核包：

- 品牌事实库。
- 风险与事实校验。
- 三份内容成果与模型、提示词元数据。
- 审核记录摘要。

## 常见问题

### 为什么点击生成后没有连接远程模型？

这是正常的降级行为。没有配置网关或网关不可达时，页面会显示“已断开”，并自动切换本地确定性演示模式。三个案例和审核流程不受影响。

### 为什么远程模型失败后仍能生成内容？

网关的回退引擎与浏览器本地引擎是同一套共享事实、风险和生成逻辑，因此失败后仍能返回统一结构的内容和风险数据。

### 为什么有些内容标记“待核实”？

这表示资料里没有直接来源或置信度不足。品牌方需要提供档案、证书、检测报告或权威网页，再由人工确认。

### 可以用这个工具直接发布吗？

不可以。系统只负责资料整理、候选草稿和风险初筛。最终事实确认、品牌判断、文案修改和发布必须由人工完成。
