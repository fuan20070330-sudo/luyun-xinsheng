# 使用说明

## 登录与分页

1. 打开应用后先进入登录页。
2. 第一次使用点击“注册新账号”，填写邮箱、密码和确认密码，点击“注册并进入”。
3. 已注册后切换到“邮箱登录”，填写邮箱和密码即可登录；不需要短信或邮件验证码。
4. 密码不会保存明文。配置服务端 API 时使用服务端 scrypt 哈希；离线本地模式使用 PBKDF2 加盐哈希。
5. 如果配置了服务端地址，品牌资料、生成历史和审核记录会同步到服务端；否则保存在当前浏览器。
4. 登录后按六个步骤操作：
   - 基本信息
   - 品牌资料
   - 访谈记录
   - 创作要求
   - 生成结果
   - 人工审核

每个步骤只显示当前输入区域，点击“确定”进入下一步，不需要在长页面中连续下滑。

## 基本信息

可以在下拉框选择已有品牌，也可以点击“新建品牌”清空当前品牌状态并填写新品牌。确认品牌名称、类型和语气后，点击“下一步：录入品牌资料”。

## 品牌资料

填写品牌历史、产品资料、荣誉登记和可引用的工艺原文。可以导入 TXT、Markdown、JSON、CSV；配置服务端解析器后还可处理 PDF、DOCX、图片 OCR 和音频转写。每行建议是一条可以直接引用的信息。

## 受访内容

填写传承人访谈、品牌方口述或客户反馈。系统会提取访谈洞察和人物线索。没有来源的信息显示“待核实”。

点击“提取事实并进入下一步”后进入创作要求。

## 创作要求

1. 选择发布平台。
2. 选择主要输出组合。
3. 填写目标受众、叙事主题、共创目标和限制条件。
4. 选择宣传方法，可多选：
   - 品牌故事线
   - 文化知识科普
   - 场景化种草
   - 传承人 IP 化
   - 节点内容日历
   - 用户共创与 UGC
   - 搜索长尾内容
   - 线上线下联动
5. 点击“生成内容方案”。

宣传方法会进入生成结果、AI 提示词和 Markdown 导出文件。

## 生成历史

顶部导航点击“历史记录”，可以查看当前账号保存过的生成任务。切换账号后，只会显示该账号自己的记录，不会看到其他账号的内容。

每条记录包含品牌、主题、平台、内容类型、模型、提示词版本、事实数量、风险数量、宣传方法和审核次数。点击“查看生成内容”可恢复到生成结果页，继续查看、审核和导出。

## 生成结果

系统生成：

- 品牌故事
- 内容日历
- 多平台文案
- 年轻化表达方案

每项结果显示事实引用、模型、提示词版本和参考宣传方法。

## 人工审核

- “品牌确认”：确认事实、文化内涵和对外表达。
- “品牌方修改”：保留 AI 原稿并保存品牌确认稿。
- “退回修改”：记录需要修改的原因。
- “复制”：复制当前成果。

确认记录包含当前用户、动作、前后内容、时间和任务编号。
