# 使用说明

## 登录与双工作线

1. 打开应用后先进入登录页。
2. 第一次使用点击“注册新账号”，填写邮箱、密码和确认密码，点击“注册并进入”。
3. 已注册后切换到“邮箱登录”，填写邮箱和密码即可登录；不需要短信或邮件验证码。
4. 密码不会保存明文。配置服务端 API 时使用服务端 scrypt 哈希；离线本地模式使用 PBKDF2 加盐哈希。
5. 如果配置了服务端地址，品牌资料、生成历史和审核记录会同步到服务端；否则保存在当前浏览器。
6. 登录后在工作台选择“生成文稿”或“修改文稿”，桌面端两条工作线左右各占一半；顶部“工作台”按钮可以随时切换。

## 生成文稿

进入生成线后按六个步骤操作：

1. 基本信息
2. 品牌资料
3. 访谈记录
4. 创作要求
5. 生成结果
6. 人工审核

每个步骤只显示当前输入区域，点击“确定”进入下一步，不需要在长页面中连续下滑。

## 修改文稿

1. 在工作台进入“修改文稿”。
2. 从当前账号的历史生成稿中选择一篇，或导入 TXT、Markdown、JSON、CSV；在线网关配置解析服务后可导入 PDF、DOCX。
3. 在“希望保留的重点”中填写不能删除或不能改写的事实。
4. 在“修改要求”中写明篇幅、语气、平台、结构、事实边界和禁用表达。
5. 点击“先排查问题语段”，查看每条问题的事实绑定状态、证明义务、风险原因和修改建议。
6. 可以点击“定位原文”跳转到对应句子，也可以点击“采用安全改写”处理单个风险语段。
7. 点击“按要求生成修订稿”，系统会在不新增知识库事实的前提下处理风险表达和修改要求。
8. 人工继续编辑修订稿，然后复制、导出 Markdown 或保存改稿记录。原文、AI 修订稿、修改要求和问题摘要分别保留。
9. “逐段修订建议”中可以接受、忽略或手动编辑每个问题语段。
10. “平台与品牌规则”会检查目标平台字数、结构和标准/禁用表达。

## 发布证据门禁

生成结果页会显示“发布证据门禁”。关键事实未确认、原文无法定位、存在高风险表达或品牌禁用词时，品牌确认和最终批准会被阻止。点击“确认所有有来源事实”可以批量确认有来源摘录的事实，无来源内容继续保持待核实。

事实卡片中的“查看原文与位置”可以展开来源摘录、文件名、页码/行号和 SHA-256 指纹。

## 多人协作审核

1. 顶部点击“协作审核”。
2. 选择一条生成记录作为内容快照。
3. 填写协作空间名称、受邀邮箱和成员角色。
4. 受邀账号登录后能看到该协作空间，保存评论和审核动作。
5. 审核人或品牌负责人可以批准；存在证据门禁阻断项时，服务端拒绝批准。

## 账号数据

顶部点击“账号数据”可以导出账号 JSON、清除本次导入文本，或输入 `DELETE` 后永久删除账号及服务端记录。

## 广告词实验室

顶部点击“广告词实验室”，填写目标受众、平台和品牌气质后生成候选。系统会给出时间、工艺、产品、场景、人物和品牌态度等不同角度，并显示事实编号、自然度分数和套话提醒。复制前仍需人工核对品牌表达。

## 基本信息

可以在下拉框选择已有品牌，也可以点击“新建品牌”清空当前品牌状态并填写新品牌。确认品牌名称、类型和语气后，点击“下一步：录入品牌资料”。

## 品牌资料

填写品牌历史、产品资料、荣誉登记和可引用的工艺原文。可以导入 TXT、Markdown、JSON、CSV；配置服务端解析器后还可处理 PDF、DOCX、图片 OCR 和音频转写。每行建议是一条可以直接引用的信息。

## 受访内容

填写传承人访谈、品牌方口述或客户反馈。系统会提取访谈洞察和人物线索。没有来源的信息显示“待核实”。

点击“提取事实并进入下一步”后进入创作要求。

## 创作要求

1. 选择发布平台。
2. 选择主要输出组合。
3. 填写目标受众、叙事主题、共创目标和限制条件。
4. 选择宣传方法，可多选：
   - 品牌故事线
   - 文化知识科普
   - 场景化种草
   - 传承人 IP 化
   - 节点内容日历
   - 用户共创与 UGC
   - 搜索长尾内容
   - 线上线下联动
5. 点击“生成内容方案”。

宣传方法会进入生成结果、AI 提示词和 Markdown 导出文件。

## 广告语与脚本体检

顶部点击“文案体检”，可以直接粘贴已有广告语、品牌介绍、短视频口播或公众号文案。系统会输出综合体检分、逐句 Claim 状态、风险词、证据缺口、模板化表达和安全改写参考。

## 生成历史

顶部导航点击“历史记录”，可以查看当前账号保存过的生成任务。切换账号后，只会显示该账号自己的记录，不会看到其他账号的内容。

每条记录包含品牌、主题、平台、内容类型、模型、提示词版本、事实数量、风险数量、宣传方法和审核次数。点击“查看生成内容”可恢复到生成结果页，继续查看、审核和导出。展开“版本历史”后，可以选择任意旧版本恢复；恢复动作会生成新的审核记录，不会覆盖历史。

点击“请求权威核验”会查询 Wikidata 和中文维基百科等公开外部来源；公开百科只作为二级参考，不会代替官方核验。

## 生成结果

系统生成：

- 品牌故事
- 内容日历
- 多平台文案
- 年轻化表达方案

每项结果显示事实引用、模型、提示词版本和参考宣传方法。

## 人工审核

- “品牌确认”：确认事实、文化内涵和对外表达。
- “品牌方修改”：保留 AI 原稿并保存品牌确认稿。
- “退回修改”：记录需要修改的原因。
- “复制”：复制当前成果。

确认记录包含当前用户、动作、前后内容、时间和任务编号。
