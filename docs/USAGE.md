# 使用说明

## 登录与分页

1. 打开应用后先进入登录页。
2. 填写任意非空账号、密码和操作身份，点击“登录”。
3. 密码不会上传，也不会写入浏览器存储。
4. 登录后按六个步骤操作：
   - 基本信息
   - 品牌资料
   - 访谈记录
   - 创作要求
   - 生成结果
   - 人工审核

每个步骤只显示当前输入区域，点击“确定”进入下一步，不需要在长页面中连续下滑。

## 基本信息

填写已有品牌或新建品牌，并确认品牌名称、类型和语气。完成后点击“下一步：录入品牌资料”。

## 品牌资料

填写品牌历史、产品资料、荣誉登记和可引用的工艺原文。可以导入 TXT、Markdown、JSON 或 CSV。每行建议是一条可以直接引用的信息。

## 受访内容

填写传承人访谈、品牌方口述或客户反馈。系统会提取访谈洞察和人物线索。没有来源的信息显示“待核实”。

点击“提取事实并进入下一步”后进入创作要求。

## 创作要求

1. 选择发布平台。
2. 选择主要输出组合。
3. 填写目标受众、叙事主题、共创目标和限制条件。
4. 选择宣传方法，可多选：
   - 品牌故事线
   - 文化知识科普
   - 场景化种草
   - 传承人 IP 化
   - 节点内容日历
   - 用户共创与 UGC
   - 搜索长尾内容
   - 线上线下联动
5. 点击“生成内容方案”。

宣传方法会进入生成结果、AI 提示词和 Markdown 导出文件。

## 生成结果

系统生成：

- 品牌故事
- 内容日历
- 多平台文案
- 年轻化表达方案

每项结果显示事实引用、模型、提示词版本和参考宣传方法。

## 人工审核

- “品牌确认”：确认事实、文化内涵和对外表达。
- “品牌方修改”：保留 AI 原稿并保存品牌确认稿。
- “退回修改”：记录需要修改的原因。
- “复制”：复制当前成果。

确认记录包含当前用户、动作、前后内容、时间和任务编号。
