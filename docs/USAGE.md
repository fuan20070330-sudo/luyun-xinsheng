# 使用说明

## 快速演示

1. 打开页面，确认顶部状态为“已连接、连接中或已断开”。
2. 点击“一键叙事演示”。
3. 系统自动载入鲁香斋模拟品牌，并处理品牌档案和受访记录。
4. 自动生成：
   - 品牌故事。
   - 内容日历。
   - 多平台文案。
   - 年轻化表达方案。
5. 风险和文化校验完成后，演示品牌确认人会确认品牌故事，生成确认留痕。
6. 可导出 Markdown 审核包。

## 输入品牌资料

1. 在“品牌档案与访谈库”选择已有品牌或新建品牌。
2. 填写品牌名称、类型、语气。
3. “品牌历史与产品资料”建议每行包含一条可直接引用的原始信息。
4. “受访内容 / 口述记录”用于录入传承人访谈、品牌方口述、客户反馈。
5. 文件导入支持 TXT、Markdown、JSON、CSV。
6. 点击“提取品牌事实”。

事实分类包括历史、工艺、荣誉、人物、产品、品牌理念和访谈洞察。没有来源的类别标记“待核实”。

## 生成四类成果

1. 选择发布平台。
2. 选择完整叙事包、品牌故事、内容日历或多平台文案作为主要输出组合。
3. 填写目标受众、叙事主题、共创目标和限制条件。
4. 选择品牌故事案例、访谈与节令或边界表达测试案例。
5. 点击“通过 WebSocket 生成叙事包”。

无论选择哪个组合，系统都会生成品牌故事、内容日历、多平台文案和年轻化表达方案。

## 风险与文化校验

系统会检查：

- 医疗和保健功效。
- 绝对化宣传。
- 非遗身份、宫廷身份和荣誉真实性。
- 文化正统性、祖传和失传等表述。
- 无依据年份。
- 无法验证的工艺。
- 低糖、无糖等营养健康声称。

高风险内容必须由品牌方修改确认，不得直接对外发布。

## 品牌方确认

- “品牌确认”：确认事实、文化内涵和对外表达。
- “品牌方修改”：保留 AI 原稿并保存品牌确认稿。
- “退回修改”：记录需要继续修改的原因。
- “复制”：复制当前成果。

确认记录包含品牌确认人、动作、修改前后内容、时间、任务编号和成果编号。

## 导出与留痕

Markdown 导出包含品牌事实库、风险与事实校验、四类成果、模型、提示词版本、事实引用和品牌确认记录。

## 常见问题

### 没有连接远程模型怎么办？

页面会进入本地演示模式。事实提取、四类成果、风险校验和品牌方确认仍可完整运行。

### 为什么访谈内容有独立分类？

访谈洞察用于保存受访原意、传承人判断和品牌方观点。AI 只能整理原意，不能替代受访者补写文化解释。

### 可以自动发布吗？

不可以。系统只提供资料整理、初稿和风险初筛。品牌方必须确认事实、文化内涵和对外表达。
