可运行

无构建静态前端

原生 HTML、CSS、JavaScript，相对路径适配 GitHub Pages 子目录，无外部 CDN 与前端密钥。

可验证

共享确定性引擎

事实提取与风险规则在前后端复用，网关不可用时仍能完整演示，结果口径保持一致。

可追溯

任务记录模型、提示词版本、事实引用、风险、AI 原稿、人工修改稿、审核动作和时间。

可扩展

后端独占密钥

远程模型只由 Node 网关读取环境变量调用；支持 Docker、Render、Railway 与 Fly.io。
